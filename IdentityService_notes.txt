└── types/

app         → Start application
features    → Business functionality
components  → Reusable UI ,resuable any where 
hooks       → Reusable logic,same logic we use any where 
services    → Backend communication
utils       → Helper functions
layouts     → Page template
assets      → Static files
types       → Data shapes
constants   → Fixed values
